ProxyGit

A versioned file proxy for AI agents and humans. Content-addressed blocks over QUIC, mounts via WebDAV, agent tools via MCP. Bring your own network — Tailscale, WireGuard, LAN, or localhost.

View on GitHub Quickstart README

What it solves

  • Agents get structured MCP tools instead of shelling cat/sed on a full checkout.
  • Bandwidth stays low: FastCDC chunks + BLAKE3 — only touched blocks move.
  • Mount friction drops: WebDAV works without kernel extensions; CLI needs no mount at all.
proxygit-client write $SERVER $PROJECT src/main.rs 'fn main() {}'
proxygit-client ls    $SERVER $PROJECT
proxygit-client mcp   $SERVER $PROJECT   # agent tools on stdio

Configure the network your way

ProxyGit is transport-address based. It does not embed Tailscale. If packets reach the server, it works.

Security: no application auth yet. WebDAV is plain HTTP; QUIC has no client certs. Keep this on localhost or a private overlay — not the public internet.

Minimal local demo

# build
cargo build --release

# server (loopback)
export PROXYGIT_DATA_DIR=$PWD/data
export PROXYGIT_LISTEN=127.0.0.1:8080
export PROXYGIT_WEBDAV_LISTEN=127.0.0.1:3900
./target/release/proxygit-server &

# pin this server's cert
export PROXYGIT_SERVER_CERT=$PWD/data/server_cert.der
PROJECT=00000000-0000-0000-0000-000000000001
SERVER=127.0.0.1:8080

./target/release/proxygit-client write "$SERVER" "$PROJECT" hello.txt 'hi'
./target/release/proxygit-client cat   "$SERVER" "$PROJECT" hello.txt
